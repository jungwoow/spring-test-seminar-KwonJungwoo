### ⚠️ 실습 안내: `fail()` 코드에 대하여

본 실습 프로젝트의 테스트 메서드에는 다음과 같은 코드가 포함되어 있습니다.

```java
fail("TODO: 정상 이체 테스트를 완성하세요.");
```

**`fail()`은 JUnit에서 테스트를 의도적으로 실패시키는 메서드입니다.**

JUnit은 테스트 메서드 내부에 아무런 검증 코드가 없어도, 예외 없이 실행이 종료되면 해당 테스트를 성공한 것으로 처리합니다. 따라서 아직 테스트 코드를 작성하지 않았음에도 테스트가 통과하는 상황이 발생할 수 있습니다.

이를 방지하기 위해 **이번 실습에서는 미완성 테스트를 구분할 수 있도록 `fail()`을 미리 작성해 두었습니다.**

#### ✅ 실습 진행 방법

1. 각 테스트 메서드에 작성된 TODO를 참고하여 테스트 코드를 완성합니다.
2. 테스트 코드 작성이 끝나면 마지막의 `fail("TODO: ...");` 코드를 삭제합니다.
3. 테스트를 실행하여 작성한 검증 코드가 정상적으로 통과하는지 확인합니다.

#### 💡 실무에서도 `fail()`을 사용할까요?

`fail()`은 JUnit에서 제공하는 정식 검증 메서드이며, **실무에서도 특정 코드에 도달하면 안 되는 상황을 검증하거나 의도적으로 테스트를 실패시킬 때 사용**할 수 있습니다.

다만 이번 실습처럼 모든 테스트 메서드 끝에 `fail()`을 작성하는 것은 일반적인 테스트 작성 방식이 아닙니다. **아직 구현되지 않은 테스트를 명확하게 표시하기 위한 교육용 장치**이므로, 테스트를 완성한 후에는 반드시 제거해 주세요.

> **참고:** 아직 작성하지 않은 다른 테스트의 `fail()` 때문에 전체 테스트 실행이 실패할 수 있습니다. 실습 중에는 IntelliJ에서 현재 작성 중인 테스트 메서드만 개별 실행하는 것을 권장합니다.
